2. Critical Infrastructure Case Studies

Colonial Pipeline Incident (DarkSide Ransomware)

Root Cause: Compromised single legacy VPN account lacking MFA, enabling lateral movement from IT networks to operational/billing assets, causing a 6-day shutdown.

Tri-Star Neutralization:

  • Hardware MFA Lock: Even with stolen VPN credentials, access is blocked without the physical YubiKey FIDO2 token.
  • Zero Trust Network Access (ZTNA): Eliminates legacy remote access VPN concentrators completely.
  • Lateral Containment: Aruba Dynamic Micro-segmentation prevents IT network traffic from probing billing or SCADA boundaries.

Longhorn Pipeline & Energy Infrastructure Threat Profiles

Root Cause: Legacy OT/ICS environments connected to corporate IT networks with perimeter firewalls subject to remote code execution (RCE) zero-days and living-off-the-land (LotL) lateral escalation.

Tri-Star Neutralization:

  • CrowdStrike Falcon Behavioral Inspection: Intercepts unauthorized process spawning, memory injection, and native tool weaponization in real time.
  • Cloudflare Anycast Shielding: Prevents targeted DDoS or direct exploitation attempts against perimeter control nodes.
